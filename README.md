# GM Goldman

Corporate website developed with Spring Boot for a consulting firm specializing in business creation support, accounting, legal, tax, social assistance, and audit services.

## ✨ Key Features

* Corporate website and service presentation
* Contact and customer inquiry management
* SEO-friendly architecture
* Dynamic JSP rendering with Apache Tiles
* Email integration
* Responsive business-oriented design

## 🛠️ Technologies Used

* **Java 8**
* **Spring Boot**
* **JSP**
* **JSTL**
* **Apache Tiles**
* **Java Mail**
* **SendGrid**

## 🏗️ Architectural Highlights

* Traditional MVC Architecture
* Server-Side Rendering
* Reusable JSP Layouts
* SEO-Oriented Structure

## 📦 Project Status

**Completed • Corporate Website**

This project was developed as a professional web presence for a consulting firm, showcasing services related to entrepreneurship support, accounting, taxation, legal assistance, and auditing.
